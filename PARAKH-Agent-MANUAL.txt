PARAKH AGENT - QUICK SETUP

FIRST TIME ONLY

1. Download PARAKH-Agent.zip from the PARAKH website.
2. Extract the ZIP.
3. Open PARAKH-Agent.exe.
4. If Windows shows a security prompt, review it and choose to run the app only if you downloaded it from the official PARAKH release.
5. Return to the PARAKH website and press "Scan this PC" or "Scan connected phone".

WHAT HAPPENS AFTER THE FIRST RUN

PARAKH Agent copies itself to:
%LOCALAPPDATA%\PARAKH\PARAKH-Agent.exe

It also adds itself to the current Windows user's startup list.
After that, it starts automatically when that user signs in to Windows.
You normally do not need to open the EXE again manually.

WINDOWS SCAN

No extra setup is required after the agent is running.

ANDROID SCAN

Android scanning also requires Android Platform Tools / ADB.
Connect the phone by USB, enable USB debugging, and approve the computer on the phone.

PRIVACY / SAFETY

The PARAKH Agent listens only on 127.0.0.1 for the website status check.
It accepts only the predefined Windows and Android scan requests.
It does not accept arbitrary shell commands from the website.
